Why it is here (2026-11-12): the browser tests need a Korean font on the test machine. The old app (baepsae.html) loads
Pretendard from a CDN, and the tests block every outside address, so its Korean text falls back to a system font.
CI used to get fallback fonts from Ubuntu's package server (apt, `playwright install --with-deps`); that server's outage
on 2026-11-11 stopped CI for hours. tests/fonts/install.sh puts this file where the browser finds it, with no download.
This is the same font the site serves (fonts/pretendard, as woff2 pieces) — browsers only take system fonts as ttf/otf.
The site does not publish or load this file.
