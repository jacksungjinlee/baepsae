### K.2 Server

- One Cloudflare Worker (`api/` in this repo) with one D1 database, location hint Asia-Pacific. Deployed only by a new
  workflow from `main` after `ci` passes, with the two secrets. Server secrets (the pepper) are created by that workflow
  with `wrangler secret put` from a random value it never prints, and live only in Cloudflare.
- CORS: only `https://jacksungjinlee.github.io` (plus localhost for tests). JSON only. Every body size-capped
  (portfolio data at most 64 KB).
- Free-plan limits (Cloudflare docs, 2026-11-06): 100,000 requests a day, **10 ms of CPU per request**, D1 5 million rows
  read and 100,000 rows written a day, 5 GB. Over a limit the request fails; the app treats it like "server down".
- **Passwords within 10 ms of CPU:** Workers' WebCrypto PBKDF2 is reported to stop at 100,000 iterations, below OWASP's
  600,000, and even that may not fit in 10 ms. So the **browser** derives the key: PBKDF2-HMAC-SHA256, 600,000
  iterations, salt `"baepsae:v1:" + 아이디`, 256 bits. The server stores only `SHA-256(per-user random salt ‖ derived key
  ‖ pepper)` and a version number (v1), so the work factor can rise later. A stolen database still costs 600,000
  iterations per guess and also needs the pepper. Benchmark the browser step on a mid-range phone and report the time.
- **복구 코드:** 12 characters from an unambiguous alphabet (no 0/O, 1/I/L), shown once as XXXX-XXXX-XXXX; stored like the
  password (salted, peppered hash). Using it sets a new password, ends all sessions and issues a new code, shown once.
- **Lock:** 5 wrong passwords for one 아이디 → 10 minutes locked; the same for wrong 복구 코드 tries (separate counter).
  Per network address: at most 30 login tries an hour and 5 new accounts a day (store a peppered hash of the address
  with an hourly or daily window, never the address itself; delete old windows).
- **Sessions:** a random 32-byte token sent as `Authorization: Bearer`; the server keeps only its hash with an expiry
  (30 days with "이 기기에서 로그인 유지", otherwise 12 hours). Kept in localStorage with 유지 on, sessionStorage
