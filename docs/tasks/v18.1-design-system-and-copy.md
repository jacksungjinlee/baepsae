## Part 1 — Tokens and fonts

| Token | Value | Use |
|---|---|---|
| ink | `#1C2B45` | Main text, primary buttons |
| text-2 | `#5B6576` | Secondary text (passes 4.5:1 on white and on `#F5F3EF`) |
| text-3 | `#6B7280` | Small labels **on white only** |
| page | `#F5F3EF` | Page background between sections |
| surface | `#FFFFFF` | Sections |
| line / border | `#F0EDE8` / `#E8E4DE` | Hairlines / control borders |
| apricot | `#C97757` | Highlights and marks only, never body text |
| apricot-text | `#A9542F` | Apricot-coloured text |
| hero-calm / hero-alert | `#EDF4EF` / `#FBF1EA` | 오늘 hero band: 할 일 없음 / 확인할 것 |
| up / down | `#D6303F` / `#2563EB` | Price up / down (Korean convention) |
| ok | `#1F7A4D` on `#E7F4EC` | 괜찮아요 |
| watch | `#8A5A00` on `#FFF3D6` | 지켜봐요, warnings |
| broken | `#FFFFFF` on `#1C2B45` | 규칙 깨짐 |
| neutral chip | `#3D4B63` on `#EEF0F4` | 큰 움직임, 예시, tags |

- **Status colours never use red or blue**, because those mean price direction in Korea.
- Every text/background pair ≥ 4.5:1. List the checked pairs in the PR.
- Font: **Pretendard** (SIL Open Font License 1.1), self-hosted woff2 with the licence file committed; Korean subset if
  size requires. Fallback: `-apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif`.
  `font-variant-numeric: tabular-nums` on all numbers.
- Type scale 28 / 22 / 18 / 16 / 15 / 13 / 12 px; weights 800 / 700 / 600 / 400. Spacing on a 4 px grid; radius 12 / 14
  / 20; touch targets ≥ 44 px.
- Icons: one inline stroke-SVG set (24 px, 2 px stroke). No emoji anywhere.
