## The rules that matter most here

1. **A verdict never claims more than was checked.**
   - Every holding's rule book lists each rule as **checked** (with its number and the report it came from) or
     **준비 중** (we can't check it automatically yet).
   - The 오늘 hero says how many rules couldn't be checked, every day there are any.
   - 할 일 없음 never hides an unchecked sell condition.
2. **Stale or failed data stops the daily check.** If the data is stale (the v17.5 rule: `publishedAt` more than 4
   days old) or failed to load, 오늘 shows that state and **never 할 일 없음**. No status is computed from it
   (`REDESIGN.md` §2.4).
3. **Only data in the v17.5 format is accepted.**
   - `app.html` refuses files without `pxDate` and `publishedAt`, and shows the load-failure message.
   - Parts A and B merge only after the first `main` run of the v17.5 pipeline has published (planned Monday
     2026-11-02).
4. **A dividend drop is never 규칙 깨짐 on its own in the beta.** `dps3` isn't adjusted for splits and includes special
   dividends; 134 Korean stocks show a "drop" today, 현대차 among them. A drop puts the stock in **확인 필요**, and the
   user confirms whether it is a real cut.
5. **A rule input that existed when the stock was bought and is blank today means 확인 필요**, never 괜찮아요.

## Part C — The rule engine (second PR)

Implement `REDESIGN.md` §2 and §4.1 in the browser. Daily decision order:
1. sell condition → 규칙 깨짐;
2. keep condition failing, or 확인 필요 → 지켜봐요;
3. bands 0.75 / 1.25 / 1.4;
4. otherwise 할 일 없음.

| Rule | Beta status | Input |
|---|---|---|
| Dividend drop | **checked → 확인 필요** (rule 4 above). Once the user confirms a real cut → 규칙 깨짐. | `dps`, `dps3` |
| Audit opinion, 횡령·배임, unrelated large acquisition | **준비 중** (v18.0 Part G, v18.2) | — |
| 부채비율 ceiling (not financials) | **checked** | `debt` |
| ROE floor (from a 수익성 card) | **checked** | `roe` |
| Operating profit down 2 years running | **checked**, annual. Confirm the order and periods of `op` in code. Quarterly comes with v18.0. | corp.json `op` |
| 중국 매출 비중, CET1, K-ICS, occupancy | **준비 중** (v18.2) | — |
| Weight bands | **checked** | prices, holdings |

- **Price never triggers a rule.** A daily move of ±5% only adds the 크게 움직인 종목 note.
- Every status line quotes the rule, the number and the report period.
