## The one rule that matters most here

A verdict must never claim more than was checked.
- Every holding's rule book lists each rule in one of two groups: **checked today** (with the number and its date), or
  **"준비 중"** (we can't check it automatically yet).
- The 오늘 hero says how many rules couldn't be checked, every day there are any.
- 할 일 없음 never hides an unchecked sell condition. This is disaster 1 in a new form: a calm screen built on half the
  rules.

## Part C — The rule engine (second PR)

1. sell condition fired → 규칙 깨짐;

4. otherwise 할 일 없음.
